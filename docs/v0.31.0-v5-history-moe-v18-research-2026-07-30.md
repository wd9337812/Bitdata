# v0.31.0 V5 历史回放与 MoE v1.8 研究记录

日期：2026-07-30  
范围：Binance 公开 1 分钟数据、VPS V5 实盘与影子记录  
线上版本：`extreme_v5_roll@v5.2`  
研究候选：`s0_binance_moe_v1_8`  
结论：研究候选保留，**不接管实盘，不签发实盘准入许可证**。

## 一、数据口径

- 公共候选源：2,143,799 条，119 个币种。
- 公共训练使用：998,068 条，按“币种 + 方向 + 30 分钟事件组”去重限权。
- 底层 1 分钟原始行情：约34,192,395条。
- 最新 VPS V5 精确记录：去重后16,285条，11,954个独立事件组。
- VPS来源按实盘、决策影子、探索影子分开计权；旧 V3/V4 不参与当前候选准入。
- 公共标签明确计入0.12%往返成本；另做1.5倍和2.0倍成本压力测试。
- 训练切分为三段滚动时间窗口，事件组不跨训练、验证、测试，避免同一行情波次泄漏。

## 二、MoE v1.8 结果

最终滚动测试（159笔、84个币种、4种市场状态）：

| 成本口径 | 净收益百分点 | PF | 最大回撤百分点 |
| --- | ---: | ---: | ---: |
| 1.0倍成本 | +5.6910 | 1.0854 | 14.0281 |
| 1.5倍成本 | -3.8490 | 0.9469 | 18.7037 |
| 2.0倍成本 | -13.3890 | 0.8296 | 23.9237 |

验证窗口在1.0倍成本下净收益为 `-4.6123`、PF `0.899`；1.5倍成本下净收益为 `-10.7323`、PF `0.7823`。

这意味着模型在最理想的成本假设下略有正值，但无法覆盖滑点、手续费上升或执行不确定性。按照实盘准入标准，它属于研究影子，不属于可上线策略。

## 三、V5.2、V5.3与退出结构

统一公开分钟路径回放显示：

- 当前短打档案：`0.85 ATR止损 / 1.05R止盈 / 10分钟上限`，开发、验证、测试均为负。
- `0.65 ATR / 1.30R / 8分钟`：测试仍为负。
- `0.90 ATR / 1.50R / 20分钟`：测试仍为负。
- `1.00 ATR / 1.80R / 30分钟`：测试仍为负。
- `1.20 ATR / 2.00R / 60分钟`：测试接近盈亏平衡，但验证仍为负，不能据此上线。

因此，失败原因不是单独由“做多/做空方向”或某个排名门槛造成，而是当前候选生成、波动路径、退出结构和交易成本组合起来没有形成稳定正期望。扩大杠杆或把单笔风险提高到30%不会修复负期望，只会放大回撤。

## 四、实施内容

新增研究工具：

- `scripts/train_s0_moe_v1_8.py`
  - 约百万公共训练样本；
  - 事件组隔离；
  - 三折滚动样本外；
  - 1.0/1.5/2.0倍成本压力测试；
  - 研究产物默认不覆盖线上模型。
- `scripts/benchmark_s0_exit_profiles.py`
  - 从119个币种的原始1分钟K线重新重标止盈止损路径；
  - 固定多个退出档案；
  - 同时输出开发、验证、测试窗口。

这些脚本只生成研究报告和候选模型，不改变实时准入、仓位、止盈止损、日止盈或5U硬停止。

## 五、下一步

当前不建议补充资金，也不建议把V5.3或MoE v1.8直接接实盘。下一轮应优先做：

1. 用最新VPS记录继续积累独立样本，尤其拆分决策影子与探索影子。
2. 重新检查候选生成是否把“有足够波动但扣费后空间不足”的机会送进了训练。
3. 研究带动态波动目标和成本门槛的候选，但必须在1.5倍成本压力下通过验证。
4. 只有连续滚动窗口、跨市场状态均通过，才考虑受限影子许可证；在此之前保持V5.2实盘和新模型研究隔离。
