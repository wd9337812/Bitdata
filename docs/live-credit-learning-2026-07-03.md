# 实盘信用分学习层

日期：2026-07-03

## 目标

让系统把真实成交结果纳入决策：盈利的币种方向逐步获得信任，亏损、快速止损、连续亏损的币种方向被降权、降仓或冷却。

信用分按“币种 + 方向”独立计算，例如 `LABUSDT SHORT` 和 `LABUSDT LONG` 是两条不同记录。

## 数据来源

- Binance U 本位合约成交：`/fapi/v1/userTrades`
- Binance 收益流水：`/fapi/v1/income`
- 本地 SQLite 表：
  - `live_trade_records`：完整开平仓归因
  - `symbol_live_scores`：币种方向信用分

部署后会跑一次历史初始化，默认回看 `96` 小时。

## 默认打分

默认信用分：`50`

奖励：

- 单笔净盈利：`+3`
- 净盈利 >= `0.7U`：额外 `+2`
- 净盈利 >= `2U`：额外 `+4`
- 连续 2 笔盈利：额外 `+3`
- 连续 3 笔盈利：额外 `+5`
- 手续费占盈利低于 10%：额外 `+1`
- 持仓时间超过 90 秒：额外 `+1`

惩罚：

- 单笔净亏损：`-5`
- 净亏损 >= `0.7U`：额外 `-3`
- 净亏损 >= `2U`：额外 `-8`
- 60 秒内快速止损：额外 `-8`
- 连续 2 笔亏损：额外 `-8`
- 连续 3 笔亏损：额外 `-15`

## 执行动作

| 信用状态 | 分数 | 动作 |
|---|---:|---|
| 强信任 | >= 80 | 提高排序，最大仓位倍率 `1.15x` |
| 正常信任 | >= 65 | 正常执行 |
| 观察区 | >= 45 | 仓位倍率 `0.70x` |
| 弱信任 | >= 30 | 仓位倍率 `0.45x` |
| 惩罚区 | < 30 | 默认只观察，不实盘 |

连续盈利达到 3 笔后，会触发“防追尾”：

- 信号仍可执行
- 排序扣 `3` 分
- 仓位再乘 `0.75`

## 冷却

- 普通亏损：30 分钟
- 快速止损：2 小时
- 同方向两连亏：4 小时
- 同方向三连亏：24 小时

冷却只影响同一币种方向，例如 `TLMUSDT LONG` 被冷却，不影响 `TLMUSDT SHORT`。

## Dashboard

新增菜单：`实盘学习`

展示：

- 币种、方向、信用分、状态
- 交易数、胜率、净盈亏、PF
- 连续盈亏、平均持仓、冷却结束时间
- 学习备注

也提供“同步历史信用分”按钮，用于手动重新拉取 Binance 历史成交并重建信用分。

## 风控说明

该层不会直接关闭已有持仓，也不会撤销已有保护单。它只影响下一次扫描产生的新候选：

- 调整候选最终评分
- 调整开仓风险百分比
- 对惩罚区/冷却中的币种方向禁止新开实盘

因此 VPS 部署时只需要重建服务并确认原有持仓保护单仍存在。
