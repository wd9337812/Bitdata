# v0.18.0 / V4.8 质量、衰竭与再入场

## 目标

V4.8 修复 V4.7 在 S0 中暴露的三个结构问题：只看本轮相对排名会把弱市场里的第一名误认为好机会；趋势末端容易追价；同币同方向亏损后缺少对“原结构延续”和“新结构形成”的区分。

## 实盘准入

- 相对门：候选仍需进入本轮前 20%。
- 绝对门：质量分至少 56，扣费后期望至少 0.03%，保守期望不低于 -0.03%，毛利成本比至少 1.70。
- 聪明钱：仅当数据可用、置信达标、中周期路径有效且不过度追价时，最多修正正负 2 分。
- 趋势衰竭：综合扩张距离、冲量、逆向影线、量能衰退、中周期路径和聪明钱背离；达到谨慎线降仓，达到禁止线不追价。
- 再入场：同币同方向连续亏损后，只有回踩阶段、路径效率、量能和扩张距离共同显示新结构时才重置；否则一次亏损降仓，两次同结构亏损暂停该局部组合。
- 局部证据：当前版本、同市场状态、方向、形态和阶段隔离。严重同类影子负证据可硬阻断，普通负证据只抬高质量门槛并降低仓位。

## 证据与性能

- V4.8 实盘和影子记录使用独立版本号，旧版本不能直接放行。
- V4.7 只作为有上限的启动先验，当前版本样本增加后自然衰减。
- 每个候选记录“去掉聪明钱的评分”和“按 V4.7 旧门槛是否通过”两个同机会反事实，避免额外运行一套扫描器。
- 自适应和局部证据读取 SQLite 并缓存，不新增 Binance REST 请求；趋势衰竭与再入场只使用已在扫描链路中的数据。

## 不变的安全边界

- S0 仍为单仓全进全出，使用约 90% 可用保证金，动态 3-10 倍杠杆。
- 计划风险 8%-15%，压力风险硬上限 15%。
- 5U 权益硬停止、交易所端止盈止损、裸仓补保护、最小下单量、流动性硬门、API 限频和时间同步不得绕过。

## 验收

- 本轮第一名但绝对质量不足时不得实盘。
- 趋势衰竭达到禁止线时不得实盘。
- 同结构连续两次亏损时阻断；满足新结构重置条件后恢复。
- V4.8 风险计算不得超过 15% 压力上限。
- Dashboard 同时展示排名、净期望、同类证据、聪明钱、衰竭状态和再入场状态。
