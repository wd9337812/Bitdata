# S0 实盘运行手册（2026-08-04 起）

## 目标

账户权益从约 15U 走到 10000U。目标保持激活；未达成前不主动终止。所有策略改动必须走：前端同步 → Git 更新 → 留档 → 测试 → 上线。

## 当前线上配置（v0.31.6）

- 主路线：30 日山寨动量（`s0_xmom_30d_live_v1`），多空双向。
- 风险：20% 起步，权益 ≥30U 自动升 22%；2 倍杠杆、90% 保证金上限。
- 止损/止盈：2.5 ATR 止损、3.5R 止盈、最长 5 天、最大止损 12%。
- 方向门：冻结审计全样本放行（多头 PF 2.52、空头 PF 1.49）；影子证据 ≥8 笔后滚动接管。
- 当日净利润锁：+200% 才锁新仓；5U 硬停止 + 0.5U 预留不变。
- BNB 后备：28/56 日趋势共振，20% 风险、15% 止损、5 天持有、无止盈。

## 健康检查清单（每轮开始执行）

1. `/api/status`：`bot=running`、`last_error=''`、权益和未实现盈亏。
2. 持仓：`runtime_protection_positions` 与 Binance 实际持仓一致；止损/止盈 algo 单都在（reduce-only）。
3. 方向门：`adaptive_30d_direction_gate` 多空均放行（当前预期）。
4. 日志：`docker logs --since 2m` 无 ERROR/Traceback；容器重启次数 0。
5. 磁盘：`df -h /` 剩余空间充足；备份目录正常。
6. 追踪：`scripts/track_s0_live_vs_baseline.py`（在 VPS runner 容器内运行）。

## 基线参照（历史等价路径，非收益承诺）

- 85 笔（多头 45 / 空头 40）、PF 1.802、净 +338.85 点。
- 20%/22% 阶梯终值 177.51U（15U 起步），最大回撤 64.6%，按年重启无 5U 硬停止。
- 复算：`scripts/audit_s0_altcoin_30d_live_config.py`。

## 触发条件与动作

| 事件 | 动作 |
| --- | --- |
| AKE 触发止损/止盈 | 记录实际滑点与收益，与基线单笔对照；若显著差于 0.60% 成本假设，查执行缺口 |
| UTC 日窗口（00:02-00:45） | 检查新候选与方向门；确认 3.5R 保护单按新参数创建 |
| 影子闭合 ≥8 笔 | 方向门自动切换到滚动影子证据；检查多空各自 PF |
| 实盘闭合 ≥10 笔 | 用追踪脚本与基线 PF/胜率/成本对照 |
| 实盘连续跑输基线 | 优先查执行缺口（滑点、资金费率、保护单、时间同步），不直接改参数 |
| 出现新研究候选 | 必须过跨年审计 + 前端同步 + 留档 + 全量测试后才能上线 |
