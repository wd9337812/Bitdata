# 双腿跨所套利压力测试：拒绝（2026-08-05）

## 假设与数据

- 同一 23 币 × 2020-2025 的 Binance/Bybit 1m 数据（4445 万行 Bybit + 1.976 亿行 Binance）。
- 信号：价差 |premium| ≥ 阈值 且 z ≥ 阈值（点对点滚动 1 天）。
- 执行：贵腿做空 + 便宜腿做多，入场重校验方向（翻转放弃），价差收窄 50% 平、
  扩大 2 倍止损、60 分钟时间退出；下一分钟开盘成交；单对串行。
- 成本：Binance 5+2bps、Bybit 5.5+2bps，5x/腿，按双腿总保证金折算权益。

## 开发期（2020-2022）结果

| 场景 | 笔数 | 胜率 | PF | 净收益% | 说明 |
| --- | ---: | ---: | ---: | ---: | --- |
| 基准（同分钟双腿） | 1,450 | 77.8% | 3.90 | +290 | 三年 PF 2.6-6.4 |
| Bybit 腿延迟 1 分钟 | 1,351 | 38.6% | 0.63 | -237 | **瞬间崩塌** |
| 成本 ×2 | 1,450 | 21.9% | 0.36 | -235 | **瞬间崩塌** |
| 剔除 |premium|>1% | 1,441 | 77.7% | 4.20 | +249 | 回撤降到 4%，但同样依赖同分钟成交 |

## 结论

1. 修复“信号翻转仍追单”的伪影后，双腿策略在基准假设下看似极强（PF 3.9）。
2. 但 Bybit 腿只要晚 1 分钟入场，PF 从 3.90 跌到 0.63：利润几乎全部来自
   “两腿在同一分钟开盘价成交”的假设，这是 1 分钟粒度无法证明可执行的伪影。
3. 成本翻倍同样把 PF 打到 0.36：毛利极薄，只够基准成本。
4. 因此：跨所价差在 1m 数据上不存在可验证、可执行的正期望。
   唯一可能的残余路径是亚分钟级（秒级）双所成交验证，且需要 Bybit API 与
   低延迟执行基础设施，超出当前授权与 1m 数据能力。

拒绝该家族进入影子或实盘。脚本与数据保留，供未来亚分钟级研究使用。
