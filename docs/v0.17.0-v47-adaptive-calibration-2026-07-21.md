# V4.7 动态方向与准入校准

应用版本：v0.17.0  
策略版本：extreme_v4_roll@v4.7  
日期：2026-07-21

## 目标

V4.6.2 根据一段特定市场样本对做空固定降到 0.65x，并添加只针对做空的硬确认。这个规则容易把短期市场状态误写成永久方向偏见。V4.7 改为多空对称：同一套规则同时评价 LONG 和 SHORT，方向待遇由当前市场状态和当前版本证据决定。

## 执行逻辑

1. 市场关系分为顺势、中性、逆势，基础倍率分别为 1.00x、0.85x、0.65x。
2. 每 5 分钟最多读取一次本地 SQLite，统计当前版本 12/24 小时实盘和事件级影子结果；实盘样本权重为影子的两倍。
3. 仓位校准至少需要 6 个当前版本结束样本，成熟权重需要 16 个；单次证据修正不超过正负 0.10。
4. 排名、净期望和确认项的微调至少需要 12 个当前版本结束样本。正证据最多放宽排名 2 个百分点、净期望 0.01 个百分点和 1 个确认项；负证据对称收紧。
5. V4.6.2 仅作为 0.25 权重冷启动先验，且最多折算 4 个有效样本，不能触发门槛放宽。V4.7 当前样本成熟后由当前版本主导。
6. 逆势候选仍需更强资金流、市场匹配和中周期路径确认；该要求对 LONG 与 SHORT 完全对称。

## 安全与性能

- 动态倍率限制为 0.55x 至 1.15x，单次变化不超过 10%。
- 最终计划风险仍截断在配置上限与 15% 压力风险硬上限以内。
- 不新增 Binance REST 请求，不改变 WebSocket 订阅数；查询最多 4000 行并缓存 300 秒。
- 不修改 5U 硬停止、最小下单量、盘口流动性硬门、交易所止盈止损和裸仓补保护。
- 不使用单笔输赢直接调参，不清空历史，不混用版本准入证据。

## Dashboard

机会中心和当前策略解释新增：方向关系、动态仓位倍率、12/24 小时当前版本样本数。专家设置可查看校准上下限、样本门槛和旧版本先验权重。
