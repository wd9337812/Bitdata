# S0 Phase 1 事件通道：穷尽审计总档（2026-08-05）

## 一句话结论

截至 2026-08-05，事件通道在 Binance/Bybit 公开数据上可验证的所有候选家族
（30+ 个）均未通过“开发期选型 → 样本外盲测 → 去集中度 → bootstrap”完整协议。
没有任何候选获得上线资格；唯一正期望家族（30d 横截面动量）只允许前向研究影子。

## 审计协议（全部候选统一）

- 数据：Binance USD-M 官方归档（1h/1m，checksum 校验）+ Bybit 官方公开数据。
- 时点：信号只用已完成 K 线；下一根/下一分钟开盘成交；禁止未来函数。
- 成本：基础 0.12-0.36%，压力 0.24-0.60%（按家族口径）；滑点另计。
- 账户：单仓（或单对），权益复利；adverse-first 止盈止损。
- 选型：2020-2022 开发期冻结；2023+ 逐年样本外盲测。
- 门槛：OOS PF>1.2、逐年 PF>1、去前三币仍正、盲留组为正、bootstrap≥95%、
  无单笔归零依赖。

## 唯一剩余路径

**30d 横截面动量**（小时级历史压力 PF 1.53、bootstrap 96.2%）：

- 仅允许独立研究影子（VPS 上运行中）。
- 晋级门槛：30 笔独立闭合、≥8 币、≥2 种市场状态、压力 PF>1.2、
  去前三币仍正、bootstrap≥95%。
- 当前进度（2026-08-05）：30d 1 笔闭合；24h 截面 18 笔闭合/6 币、压力 PF 0.87。
- 检查器：`scripts/check_s0_forward_shadow.py`（已部署 VPS，自动输出门槛状态）。

## 为什么不再“换一个模型/数据源”就能解决

1. 信息集已覆盖：价格、量、OI、taker、toptrader、资金费、盘口代理、跨所价差、
   亚分钟成交——全部无跨年可扣费 edge。
2. 频率不产生免费经验：单笔毛利接近或低于 10-20bps 成本时，交易越多亏越快。
3. 少数“局部正收益”全部无法通过去集中度与年度稳定性检查。
4. 结论是数据证据，不是参数没调够；继续搜索必须换真实未来样本（前向影子）
   或新外部条件（Bybit 双账户执行、更低延迟基础设施）。
