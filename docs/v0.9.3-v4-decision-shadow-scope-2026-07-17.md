# v0.9.3 V4 决策影子证据口径修复

## 背景

V4 会同时记录两类影子交易：

- `decision`：模型本轮真正排在前列、可能进入实盘决策的候选。
- `exploration`：为了研究漏判而额外跟踪的候选，本来就不属于当前实盘决策集合。

风险保护此前把两类样本混合计算恢复 PF。V4 激活后累计 2,800 余个独立影子机会，整体扣费后 PF 约为 0.74；其中大量负收益来自广泛下跌市场中的探索组合。把这些研究样本用于恢复放行，会让 Dashboard 的恢复 PF 与实际决策策略不一致，并可能使机器人长期无法形成有效的恢复许可证。

## 本次改动

1. `extreme_v4_roll` 的全局风险保护、影子尾部恢复窗口和恢复许可证，只读取当前策略版本、`active` 角色、`decision` 类型的影子交易。
2. `exploration` 样本继续完整保存，继续用于复盘、机会漏判分析和后续策略版本研究。
3. 其他策略版本沿用原口径，不混入 V4 的证据规则。
4. Dashboard 明确显示“决策影子恢复证据”，避免用户把研究影子 PF 当成可实盘 PF。

## 未改动的边界

- 实盘策略仍为 `extreme_v4_roll@v4.0`。
- 没有修改候选排序、准入门槛、杠杆、仓位、止盈止损或换仓逻辑。
- 5U 硬停止、交易所保护单、API 频控和时间同步保持不变。
- 当前 5 笔连续亏损和权益高点回撤保护仍然有效；本修复不会直接解除 `risk_off`。

## 验证

- 新增回归测试，证明 V4 正向决策影子不会被负向探索影子污染。
- 保留现有 V3、旧版本隔离、连续亏损和恢复许可证测试。
- 完整测试、前端构建和部署后实盘安全检查记录在项目 `docs/TEST_RECORD.md`。
