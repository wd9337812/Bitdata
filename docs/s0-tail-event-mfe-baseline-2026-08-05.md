# 尾部事件 MFE 数据管线与规则基线（2026-08-05）

## 数据

- 全市场 2020-2026 点对点 1h 数据 + 资金费（已补齐 2020-2025）。
- 每日 UTC 边界候选：上市 ≥45 天、24h 成交额 ≥2000万U。
- 标签：未来 120h 内任一方向最大有利波动（MFE）≥ 2×(12% 止损 + 0.24% 往返成本) ≈ 24.5%。
- 候选数：2020-2026 约 20-47 万/年。

## 结论与下一步

- 简单规则不能可靠识别尾部事件，与仓库此前结论一致。
- 数据管线已就绪（`candidates.parquet`），下一步用 LightGBM 排序模型：训练 2020-2023、验证 2024、测试 2025、盲测 2026；要求 top1% 候选命中率显著高于基线且跨年为正、扣费后可交易。
