# v0.11.0 / V4.2 自适应双通道准入

## 为什么迭代

V4.1 已经把选币从单一总分改成“市场状态 × 方向 × 信号 × 入场阶段”的独立证据，但实盘准入过度集中在少数安静行情和回踩结构。线上复盘发现：

- 最近 72 小时旧 V3.2 影子 `944` 笔，扣费后净收益 `-34.19U`、PF `0.591`，不能继续参与当前实盘准入。
- V4.1 决策影子 `1014` 笔，扣费后净收益 `-19.5866U`、PF `0.827`，整体仍未形成正期望，不能全局放宽。
- `broad_down + SHORT + momentum` 有 `53` 个样本、净收益 `+1.311U`、PF `1.252`，说明顺势动量存在值得限次验证的局部机会。
- V4.1 将 `broad_down`、`broad_up`、`rotation` 和 `panic` 全部挡在实盘外，造成“方向判断更合理，但可执行机会明显减少”的结构性瓶颈。

因此 V4.2 不降低所有门槛，也不提高杠杆，而是在核心通道之外增加一个有边界的顺势探索通道。

## 当前执行结构

### 核心通道

核心通道保留 V4.1 的严格逻辑：

- 安静行情中的顺势突破、预突破或回踩。
- 中周期方向必须对齐。
- 需要通过动态成本、保守期望、盘口流动性、交易所最小量和当前版本负证据检查。
- 证据达到 provisional 或 validated 标准后，分别使用受限或标准仓位。

### 顺势受限探索通道

探索通道只允许以下结构：

- `broad_down`：只允许做空动量。
- `broad_up`：只允许做多动量。
- `mixed` 或 `rotation`：允许顺中周期方向的动量，或已经确认的回踩。
- `panic`：仍然只记录影子，不追价实盘。
- 所有逆势候选：仍然只记录影子。

默认准入要求：

- 本轮扣费后期望排名不低于 `0.75`，即前 `25%`。
- 模型质量分不低于 `55`。
- 扣费后融合期望不低于 `0.04%`，保守下界不低于 `-0.03%`。
- 毛利/成本比不低于 `1.60`。
- 动量候选在成交量持续性、主动成交方向、横截面强度和中周期路径中至少满足 `2/4` 项确认。
- 默认风险倍率 `0.4x`；本版本不同时提高杠杆。
- 新版本许可证默认最多尝试 `3` 个机会，累计 `2` 笔亏损即撤销。

## V3 归档与数据隔离

- V4 启用时不再运行 V3 完整质量评分、V3 校准或 V3.3 配对影子。
- Dashboard、当前实盘 API 和高频遥测不再展示或写入 V3 质量分与 V3 实验字段。
- V3 历史成交、影子记录和版本注册不删除，只标记为 `archived/retired`，便于审计和紧急回滚。
- V4.2 直接从现有行情快照构建中性 `market-structure-v1` 特征，当前实盘明确标记 `legacy_v3_quality_used_for_live=false`。
- 不同 V4 版本的证据按策略版本隔离；V4.1 的输赢不能直接决定 V4.2 的准入或仓位。

## 性能与 API 开销

- 不增加 Binance REST 全市场扫描、订单查询或深度竞价预算。
- V4.2 复用现有分片 WebSocket、K 线快照、中周期缓存和深度精排结果。
- V4 启用时跳过 V3 校准与 V3.3 配对影子，减少 CPU 和 SQLite 写入。
- 新增的准入通道只做内存特征计算；影子汇总增加一个按 `admission_lane` 的数据库聚合，不进入 runner 高频写路径。
- 旧配置中的 V3 点差和深度字段只作为迁移别名读取；当前字段统一为 `execution_max_spread_pct` 和 `execution_min_depth_notional_usdt`。

## 不变的安全边界

- `5U` 权益硬停止不变。
- 交易所端止损与止盈、裸仓补保护不变。
- 最小下单量、点差、盘口深度和预期成本检查不变。
- Binance REST 权重、订单频控、公共/私有 WebSocket 兜底和时间同步不变。
- 不手工开仓，不为部署主动平掉已有受保护持仓。

## 验证范围

- V4.2 核心准入、受限探索、逆势隔离和恐慌隔离单元测试。
- V3 归档、版本证据隔离和精简遥测回归测试。
- 全量后端测试、前端生产构建、静态资源 HTTP 冒烟测试。
- 部署前后核对真实持仓、普通订单、条件止盈止损、机器人、路由、连接和错误日志。

V4.2 的目标是增加“有方向依据且成本可接受”的真实验证机会，不代表已经证明能够盈利，也不承诺达到任何权益目标。是否继续放宽或提高仓位，必须由 V4.2 独立实盘和影子样本决定。
