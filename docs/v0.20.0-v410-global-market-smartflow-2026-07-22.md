# V4.10 全局市场状态与聪明钱代理

日期：2026-07-22

## 目标

V4.10 延续 V4.9 的单仓全进全出、扣费后期望、最小下单量、交易所保护单和 5U 硬停止。新增的是全局判断层：用当前 V4 版本的实盘与影子结果识别市场状态、方向偏置和聪明钱代理状态，避免把某个币的短期输赢误当成永久质量分。

## 规则

- 当前版本证据与旧版本隔离。V4.9 只作为 V4.10 启动先验，不直接获得当前版本准入资格。
- 统计窗口保留 12 小时、24 小时，并新增 72 小时背景窗口。全局校准每 2 小时最多改变一个门槛，单次变化仍受原有上下限约束。
- 方向偏置由当前版本最近 72 小时的多空扣费后净结果汇总得到。只有出现明确差异时，V4.10 才对顺势候选小幅增加倍率、对逆势候选小幅降低倍率；默认是 `1.05x` 与 `0.90x`，不会直接禁止逆势机会。
- 聪明钱代理复用已有短名单数据，不新增 Binance 请求。聚合字段只用于解释和全局背景，数据缺失时保持中性，不能单独触发开仓。
- 所有候选仍必须通过 V4 原有的排名、期望、成本、确认、流动性、最小下单量和保护单检查。

## 性能与安全

全局结果使用内存缓存和低频 JSON 审计，不在扫描每个币时写 SQLite，也不增加行情 API 调用。部署前后必须核对真实持仓与止盈止损；任何保护缺失优先补保护，不主动平仓或手工开仓。

## 前端

控制台和机会中心展示：当前 V4.10 版本、全局市场状态、方向偏置、聪明钱聚合状态、72 小时样本数、有效门槛和调整原因。展示明确标注“全局修正，不按币种调参”，避免把候选的瞬时聪明钱分数误读为单币永久评分。

## 回滚

将 `opportunity_v4_strategy_version` 改回 `v4.9` 即可回到旧全局校准路径；保留历史数据，不删除 V4.10 的影子记录。回滚前后都需要确认已有持仓保护单完整。
