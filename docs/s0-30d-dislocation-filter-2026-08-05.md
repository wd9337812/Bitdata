# 30d 动量 + 跨所价差拥挤过滤：首个有改善的候选（2026-08-05）

## 假设

30d 横截面动量入场时，若 Binance 相对 Bybit 已出现同向价差错位（做多时
Binance 溢价过高、做空时 Binance 折价过深），说明入场拥挤/追价，应放弃。
Bybit 数据来自官方公共档案（`public.bybit.com`），**免注册、免 API key**；
交易仍在 Binance 单腿执行。

## 数据

- 信号：`signals_all.parquet`（306 个，2021-2026）。
- Binance 路径：信号事件窗口官方 1m（92 币全覆盖）。
- Bybit：信号入场日逐笔成交→1m 聚合，覆盖 70+ 币、765 条价差记录。
- 执行：5 分钟延迟入场，压力往返成本 0.60%，72h 币种禁入。

## 结果（压力成本）

### 冻结档案（2.5 ATR 止损 / 2.5R / 5 天）

| 方向 ≤0.10% | 217 | 62 | 1.42 | +112.2 | 0.98 | 0.844 |

方向过滤：做多要求 Binance 相对 Bybit 溢价 ≤ 阈值；做空要求折价 ≤ 阈值。

### 让利润跑档案（3.5R/4R）

基线 PF 1.43-1.49、去前三 0.90-0.95、bootstrap 0.89-0.90；
加过滤后去前三与 bootstrap 未同步改善（woTop3 ≤0.82），不采用。

## 谨慎性评估

- 方向 ≤0.05% 在全样本上把冻结档案的集中度（去前三 PF 0.75→1.27）与 bootstrap
  （0.70→0.94）同步改善，是数月来第一个跨指标变好的候选。
- 若最终成立，部署成本极低：只在 30d 动量每日评估时多拉一次 Bybit 公共价格
  （免注册），不改交易结构。

## 严格开发/样本外切分（2026-08-05 补充）

冻结档案、延迟 5 分钟、压力成本 0.60%：

| 过滤 | 开发 2021-2023 | 样本外 2024-2026 |
| --- | --- | --- |
| 无（基线） | 29 笔 PF 1.19 / 去前三 0.70 | 40 笔 PF 1.14 / 去前三 0.54 |
| 方向 ≤0.10% | 26 笔 PF 1.06 / 去前三 0.54 | 36 笔 PF 1.59 / 去前三 0.95 |

结论：**改善集中在样本外（2024-2026），开发期去前三为负**。按“开发期选型 →
样本外验证”协议，该过滤不会被开发期选中，属于近年行情依赖，不能判定为稳定
正期望。候选保持研究状态，不做上线/影子部署；若前向影子需要，可在 30d 研究
影子中增加该过滤的实验分支收集未来样本。
