# 尾部事件 LightGBM v2/v3 结果：方向性标签与追踪退出仍不合格（2026-08-05）

## v2：方向性标签

- LONG/SHORT 分别打标签（mfe_up/mfe_down ≥24.5%），方向作为特征；模型同时输出方向和排序。
- 结果：方向特征重要性低（443/约 1 万），2025 top1% PF 0.114、2026 PF 1.025，合并 54 笔 PF 1.13 且触发 5U；去头部 3 币 PF 1.048。
- 不合格。

## v3：方向性标签 + 追踪退出

- 退出改为：+2R 保本、+5R 后峰值回撤 1.5R 追踪，120h 上限。
- 结果：合并 top1% 64 笔 PF 1.272，但 2025 top1% PF 0.248、2026 PF 0.978，仍触发 5U；去头部 3 币 PF 1.157。
- 不合格（单年门槛与硬停止均失败）。

## 阶段性结论

规则候选（新币、资金费、量价/OI/泵回落/基差）和机器学习 v1/v2/v3 均未通过“开发期选型 + 样本外 + 扣费后 + 去集中度”协议。当前特征与“次根开盘价入场”的执行下，尾部事件通道没有可交易正期望。

## 下一步候选（v4）

- 入场改进：对 top 候选用**回踩限价单**（次根开盘价下方 0.5×止损距离挂单，24h 内未成交放弃），而不是次根市价追单；避免在尖峰处追高，降低止损出局率。
- 数据增强：taker 失衡 / OI 变化 / 盘口成本（部分只有 2026，需评估覆盖）。
- 任一 v4 变体通过门槛才进入影子；否则 Phase 1 暂停，底仓层 20% 固定继续运行。
