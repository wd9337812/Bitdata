# MoE v1.6 精确 V5 重训记录

日期：2026-07-28
模型：`s0_binance_moe_v1_6`
用途：S0 研究影子，不接管实盘准入、仓位、止盈止损。

## 这次解决什么问题

上一版 MoE 训练把公开数据、旧 V4 版本和当前 V5 证据混在一个固定日期切分里。这样会产生两个风险：

- 旧策略的负样本稀释当前 V5 的判断；
- 验证窗口和测试窗口不随当前数据变化，不能代表最新市场状态。

v1.6 改为：

1. 只使用 `extreme_v5_roll / v5.0-s30` 的实盘与影子记录做主证据。
2. 以 `opportunity_id` 去重；同一机会同时出现实盘和影子时，实盘优先，避免重复计数。
3. 公开 Binance 数据只作为训练集的低权重辅助，不进入验证和测试。
4. 按精确 V5 时间顺序做 60% 训练、20% 验证、20% 未触碰测试。
5. 训练目标按 1.5 倍成本压力计算，并同时报告 1.0x、1.5x、2.0x 成本结果。
6. 保留 setup expert 和市场状态门槛；当前候选只在线上记录，不影响实盘。

- 2.0 倍成本净收益：`-8.411` 个百分点，PF `0.342`

## 结论

v1.6 没有通过放行条件。验证段为正，但未触碰测试段转负，且测试样本只有 15 笔、只有 1 种市场状态，不能证明模型稳定。当前最可靠的结论是：

1. V5 影子整体仍是负期望，问题不只是 MoE 门槛。
2. v1.6 可能在短窗口内抓到局部结构，但尚未证明能跨市场状态工作。
3. 不能把 10 笔正收益实盘当成模型证据，样本太小。
4. 继续让 v1.6 在线影子记录是可以的，但必须保持 `research_shadow_only` 与 `affects_live_admission=false`。
5. 下一次训练需要更多不同市场状态的 V5 独立闭合样本；仅靠继续增加同一段 panic/mixed 行情的样本，会重复验证同一个失败结论。
