# 实盘信用分线性倍率迭代

日期：2026-07-04

## 背景

上一版信用分把惩罚区和冷却直接变成“禁止开仓”。这对保守风控有效，但和 10000U 前的锦标赛目标冲突：系统会因为几个核心币种连续亏损而长时间没有动作。

本次改为“信用分控制仓位倍率”，让系统继续参与，但亏得越多仓位越小，赚回来后仓位自然变大。

## 新规则

信用分范围：`0 - 100`

开仓倍率：

```text
信用倍率 = 信用分 / 50
最终范围 = 0 - 2
```

示例：

| 信用分 | 倍率 |
|---:|---:|
| 100 | 2.00x |
| 75 | 1.50x |
| 50 | 1.00x |
| 25 | 0.50x |
| 10 | 0.20x |
| 2 以下 | 0x 熔断 |

倍率乘在当前策略风险上。锦标赛基础风险默认 `15%`，所以 100 分时理论风险为 `30%`，但仍受保证金上限、杠杆、交易所最小下单量和止损距离约束。

## 冷却不再禁止

冷却只限制倍率上限：

| 情况 | 倍率上限 |
|---|---:|
| 普通亏损冷却 | 0.80x |
| 两连亏冷却 | 0.25x |
| 三连亏冷却 | 0.10x |
| 信用分 <= 2 | 0x |

例如 `LABUSDT SHORT` 信用分 21，基础倍率是 `0.42x`。若处于三连亏冷却，则最终倍率压到 `0.10x`，仍可在强信号下极小仓试探。

## 自然恢复

亏损后的币种方向会随时间恢复，但最多恢复到默认分 `50`：

- 普通分数：每 6 小时恢复 `+3`
- 极低分：每 12 小时恢复 `+2`
- 自然恢复上限：`50`
- 超过 `50` 只能靠实盘盈利获得

这样系统不会永远记仇，但也不会因为时间流逝自动变成高信任。

## Dashboard

`实盘学习` 页面新增：

- 原始信用分和自然恢复后的信用分
- 当前开仓倍率
- 冷却倍率上限
- 下次自然恢复时间

配置中心新增：

- 信用倍率除数
- 最高信用倍率
- 熔断信用分
- 自然恢复开关、间隔、分数、上限
- 普通/两连亏/三连亏冷却倍率上限

## 风控边界

本次不会放宽市场信号本身：

- 没有信号仍不开仓
- 成本比、币种质量、深度检查仍有效
- 信用分只调整仓位倍率
- 极低信用分仍会熔断

这版更适合锦标赛阶段：继续上桌，但根据实盘成绩自动调筹码。
