# v0.32.0 V4.9 统一回放与 MoE v1.9 研究记录

日期：2026-07-30  
线上版本：`extreme_v5_roll@v5.2`  
研究候选：V4.9 静态代理、`s0_binance_moe_v1_9`  
结论：保留研究产物，**不回滚 V4.9、不让 MoE v1.9 接管实盘、不修改 VPS 策略**。

## 一、为什么重新检查 V4.9

历史记录中 V4.9 曾出现短期盈利，因此本轮没有只看版本汇总，而是同时还原：

- V4.9 的排名、质量、扣费后期望、确认项和衰竭拦截；
- V4.9 的止损、止盈和最长持仓；
- V4.9 全量影子与被选中实盘通道的差异；
- 与 V5.2 相同数据、相同成本、相同退出档案下的样本外结果。

V4.9 的历史实盘只有 4 笔，全部为 `RIFUSDT SHORT`，合计约盈利 `0.3625 U`。V4.9 的 `full_bet` 影子通道只有 19 笔，净收益 `+2.5176`、PF `2.42`；但同版本全部 1,796 笔影子净收益为 `-64.2701`。因此，历史亮点属于很小的已选择样本，不能代表整套版本具有稳定优势。

## 二、统一回放口径

- 公共候选源：2,143,799 条。
- 进入统一路径回放：186,300 条候选。
- 币种：119 个 Binance 永续币种。
- 往返手续费和滑点：固定按 `0.12%` 计入。
- 时间切分：开发、验证、测试三段，严格按时间向前滚动。
- V4.9 代理阈值来自提交 `5ce2358`。
- V4.9 代理不包含账户状态、滚动本地证据和完整盘口条件；公开数据没有同口径聪明钱背离字段，因此衰竭分数是保守近似。

当前快速退出档案为 `0.85 ATR 止损 / 1.05R 止盈 / 最长 10 分钟`：

| 策略代理 | 开发 PF / 净收益百分点 | 验证 PF / 净收益百分点 | 测试 PF / 净收益百分点 |
| --- | ---: | ---: | ---: |
| V4.9 静态代理 | 0.7401 / -1046.26 | 0.7532 / -360.62 | 0.7566 / -408.63 |
| V5.2 代理 | 0.7426 / -1529.67 | 0.7522 / -510.77 | 0.8118 / -446.58 |

另外比较了 8、20、30、60 分钟退出档案。60 分钟档案在测试段接近盈亏平衡，但开发段和验证段仍为负，未通过上线标准。

按方向、信号类型和市场状态继续拆分后，没有找到同时满足以下条件的组合：

- 开发不少于 50 笔；
- 验证和测试分别不少于 30 笔；
- 三个窗口扣费后净收益均为正且 PF 均大于 1。

这说明不能从 V4.9 中提取一条已经验证、可直接迁移到 V5.2 的实盘规则。

## 三、MoE v1.9 百万级重训

MoE v1.9 复用了已审计的 v1.8 训练管线，但使用独立模型版本和独立产物目录：

- 公共候选源：2,143,799 条。
- 公共训练样本：998,068 条。
- 公共独立事件组：429,909 个。
- 底层 Binance 1 分钟行情：34,192,395 行。
- 最新 VPS V5 精确记录：16,285 条、11,954 个事件组，去重后 4,780 条。
- 训练、验证和测试按事件组及时间隔离。

聚合结果：

| 成本压力 | 验证 PF / 净收益百分点 | 测试 PF / 净收益百分点 |
| --- | ---: | ---: |
| 1.0 倍 | 0.8990 / -4.6123 | 1.0854 / +5.6910 |
| 1.5 倍 | 0.7823 / -10.7323 | 0.9469 / -3.8490 |
| 2.0 倍 | 0.6823 / -16.8523 | 0.8296 / -13.3890 |

测试段在最理想成本下略正，但验证段为负，且成本提高到 1.5 倍后再次为负。该结果没有达到跨窗口、跨成本稳定为正的实盘标准，状态保持为 `research_shadow_only`，并明确设置 `affects_live_admission=false`。

## 四、实施内容

- `scripts/benchmark_s0_exit_profiles.py`
  - 增加可复现的 V4.9 静态研究门；
  - V4.9 与 V5.2 使用同一候选、同一路径、同一成本比较；
  - 报告中明确列出代理限制，避免把近似回放当成精确实盘复刻。
- `scripts/train_s0_moe_v1_9.py`
  - 使用最新隔离的 VPS V5 历史；
  - 复用 v1.8 已审计的百万级滚动训练流程；
  - 模型、报告和版本号与线上模型完全隔离。
- 新增针对 V4.9 结构、衰竭拦截和 MoE v1.9 隔离性的自动化测试。

## 五、上线决定

本轮没有找到通过验证的策略候选，因此：

1. VPS 继续保持 V5.2，不部署研究模型。
2. 不把 V4.9 的 19 笔精选表现外推成全局规则。
3. 不提高杠杆、仓位或风险上限来放大尚未验证的负期望。
4. 不建议为当前策略补充资金；账户已非常接近 5U 硬停止，新增资金不能修复策略期望。
5. 下一轮研究应优先改进候选标签和成本建模，而不是继续组合旧版本阈值。
