# V4.6.2 实盘证据加权迭代

日期：2026-07-21

应用版本：v0.16.2

策略版本：extreme_v4_roll@v4.6.2

## 目标

在不放宽 5U 硬停止、交易所止盈止损、盘口流动性硬门和 15% 单笔压力风险上限的前提下，根据 V4.4 以来的实盘记录调整候选排序，减少弱方向、长时间不覆盖成本的交易。

## 证据摘要

V4.4 以来共复盘 67 笔已结束实盘：胜率 56.7%，扣费后净收益 +18.4683U，PF 1.291，手续费 9.1672U。该结果为历史关联分析，不等同于新权重的样本外收益保证。

| 维度 | 低值组 | 高值组 | 结论 |
| --- | ---: | ---: | --- |
| 方向资金流 | -15.193U / PF 0.691 | +33.661U / PF 3.348 | 提高权重 |
| 量能持续 | -8.619U / PF 0.664 | +27.088U / PF 1.715 | 提高权重 |
| 市场状态匹配 | -3.580U / PF 0.901 | +22.048U / PF 1.803 | 略提高权重 |
| 中周期路径 | +0.749U / PF 1.042 | +17.719U / PF 1.387 | 提高权重 |
| 做多 / 做空 | +24.887U / PF 1.472 | -6.419U / PF 0.406 | 做空加强确认并降风险 |
| 持仓 30-120 秒 | +16.981U / PF 2.397 | - | 快速兑现表现较好 |
| 持仓 10-30 分钟 | -10.437U / PF 0.323 | - | 加快低收益时间退出 |

聪明钱有效样本只有 24 笔，高置信组表现优于低置信组，但样本仍不足。因此继续作为与方向资金流分离的软修正，最多影响最终排名正负 5 分，不能单独放行或阻断。

## 改动

- 排序权重改为：方向资金流 20%、量能持续 15%、市场状态 15%、中周期路径 17%、入场质量 12%、中周期一致 8%、横截面 8%、防追高 4%、流动性预测 1%。
- 动量 +4 分、突破 +1 分、回踩 -3 分、预突破 -3 分。
- 做空要求更强的方向资金流、市场匹配和中周期路径，并将计划风险乘以 0.65。
- 低收益持仓最长时间从 6 根 5 分钟 K 线缩短为 2 根；约 10 分钟仍未覆盖成本时由运行时保护退出。
- Dashboard 同时显示方向资金流相关 V4 指标与独立聪明钱指标，避免将二者误认为同一数据。
- 新版本使用独立证据和许可证，不混用 V4.6.1 历史准入状态。
- 时间退出迁移带有一次性标记，可修复多容器首次启动造成的部分持久化，同时保留后续人工修改参数的能力。

## 安全边界

- 5U 硬停止不变。
- 交易所端止盈、止损和裸仓补保护不变。
- 盘口点差、深度、最小下单量和 API 限频不变。
- 单笔压力风险硬上限 15% 不变；做空只会降低风险。
- 本次没有提高开仓数量上限或杠杆上限。

## 验证要求

- 策略权重、形态修正、做空准入和做空风险单元测试。
- V4.6.1 配置到 V4.6.2 的版本、许可证与时间退出迁移测试。
- 完整后端测试、前端生产构建和静态资源冒烟测试。
- 部署前后核对真实持仓及交易所保护单，确认机器人、WebSocket、REST 频控和 Dashboard 正常。
