# v0.26.0 / V5.0-S30：S0 全仓短打

日期：2026-07-28  
运行版本：`extreme_v5_roll@v5.0-s30`  
适用阶段：S0

## 目标

V5.0-S30 把 S0 明确为“单仓、全进全出、快速保护”的高风险增长模式。它不承诺收益，也不把旧 V3/V4 的负样本、信用分或许可证状态带入新的实盘准入。

## 当前执行口径

- 单仓约使用 90% 可用保证金，只允许一个币种、一个方向、一次建仓和一次全平。
- 计划压力风险区间为 12% 到 30%。12% 是普通机会基线，30% 是最强机会的压力硬上限，不代表每笔订单都会亏损该比例。
- 动态杠杆范围为 3 到 10 倍。杠杆由止损距离、手续费压力和保证金预算共同决定，不能越过压力风险上限。
- 初始止损为 0.90 ATR，止盈目标为 1.05R，盈利达到 0.45R 后开始保护到保本附近，最长持有 3 根 5 分钟 K 线。
- 通过条件必须同时考虑相对排名、质量分、扣费后期望、保守净期望、收益成本比、确认项和盘口执行条件。
- 聪明钱是软修正，最多正负 10 分，只能修正排序，不能单独触发开仓，也不会新增高频 REST 请求。
- MoE 继续只做影子研究，不接管 V5 实盘的开仓、仓位、止盈或止损。

## 连续准入与保护

- 一次净亏损：下一笔仓位倍率 `0.80x`。
- 两次连续净亏损：下一笔仓位倍率 `0.60x`。
- 三次连续净亏损：暂停新开仓 20 分钟；冷却结束后自动恢复，但下一笔暂时以 12% 风险基线运行，不需要等待旧版 PF 或人工许可证。
- 有效盈利会清除连续亏损状态并逐级恢复仓位。
- 5U 权益硬停止、交易所止盈止损、最小下单量、时间同步、API 限频和裸仓保护始终有效。
- S0 日止盈锁保持为可配置项，默认目标为 UTC 当日初始权益的 40%；达到目标且空仓后停止当天新开仓，次日自动恢复。

## 版本隔离

V5 的实盘和影子记录使用独立策略族 `extreme_v5_roll` 与版本 `v5.0-s30`。旧版本只用于历史复盘、回放和对照，不参与 V5 的准入、信用、仓位或连续准入状态。

## 性能与 API 约束

- 复用现有召回、粗排、精排、竞价漏斗，不扩大每轮 REST 请求；V5 只在现有候选短名单上完成版本化评分。
- 公共/私有 WebSocket 继续作为实时行情与账户流，REST 只做兜底和下单前余额复核。
- 影子、实时保护和 Dashboard 写入沿用现有批量/锁控制，不新增按币种永久校准状态。
- Dashboard 当前设置页只展示 V5 的实际执行参数；旧版字段保留在专家设置中并标记为历史兼容/回放用途。

## 验证边界

本版本的验证重点是版本路由、风险上限、保护参数、连续准入冷却、历史证据隔离和前端显示一致性。实盘收益仍受市场、手续费、滑点、资金费、插针和交易所执行影响，不能由回测或历史影子结果保证。
