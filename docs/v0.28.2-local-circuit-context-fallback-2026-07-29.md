# V0.28.2 局部熔断上下文兜底

## 问题

Dashboard 与 runner 会并发读写运行状态。极短持仓连续开平仓时，平仓同步可能先看到成交记录、后看到开仓上下文，导致该平仓被标记为已处理，但币种方向 episode 和策略组合 cohort 没有同步更新。

全局连续准入仍会正常降仓，但局部亏损记忆可能不完整。

## 修复

- 开仓上下文存在时继续使用原始 cohort 与 episode。
- 开仓上下文缺失时，根据平仓记录的币种、方向、市场状态、信号类型和触发阶段重建 cohort。
- episode 始终按 `币种:方向` 重建，不允许因信号名称变化绕过同方向记忆。
- 不修改 V5.1.1 的信号、准入、止盈止损、杠杆或风险阈值。

## 验证

- 新增无开仓上下文的 V5.1.1 亏损归因测试。
- 局部熔断与性能保护定向测试：26 项通过。
