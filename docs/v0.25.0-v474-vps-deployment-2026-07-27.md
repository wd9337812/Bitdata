## 部署流程改进

本次发现部署脚本缺少 Git 可执行位，首次直接运行失败，改用
`bash deploy.sh update` 后完成部署。仓库已补回 `deploy.sh` 可执行权限。

后续部署不得在旧 runner 仍运行时提前写入新策略版本配置。正确顺序为：

1. 先确认真实持仓和交易所保护单。
2. 在空仓窗口更新代码和容器。
3. 由新版本迁移配置，或在新 runner 启动前一次性写入配置。
4. 部署后再次核对版本、持仓、止盈止损、WebSocket、REST 和错误日志。
