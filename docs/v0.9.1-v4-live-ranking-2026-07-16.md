# v0.9.1 V4 实盘机会排序留档

## 结论

V4 从候选影子实验升级为 S0-S2 当前实盘机会排序器。V3.2 仍负责生成趋势、量价、市场状态等基础特征，但它的 A+/A/B 档位、旧信用分和旧版本亏损不再决定实盘准入。

这不是宣称 V4 已盈利，也不是放开全部候选。它解决的是旧质量分层已经失效，却继续控制新策略而导致长期不开仓的问题。

## 证据

部署前读取 VPS 最近 24 小时版本隔离数据：

- V3.2 A：394 笔，胜率 40.6%，净收益 -10.088183 U，PF 0.689。
- V3.2 A+：73 笔，胜率 31.5%，净收益 -5.788395 U，PF 0.476。
- V3.2 B：121 笔，胜率 52.1%，净收益 -3.236556 U，PF 0.699。
- V3.2 实盘：2 笔，毛盈亏 -0.174085 U，手续费 0.131710 U，净盈亏 -0.305795 U，PF 0.51。

这些样本足以否决“A+/A 比 B 更优”的旧排序假设，但不足以证明 V4 已经具备稳定正期望。因此采用受限探索，而不是把 V4 所有候选直接全仓实盘。

## 实盘规则

### 受限探索

候选必须同时满足：

- 趋势突破结构；
- 本轮 V4 净期望排名进入前 15%；
- V4 模型质量分不低于 58；
- 模型估算扣费后净期望不为负；
- 盘口点差和深度通过硬门；
- 当前权益满足 Binance 最小下单量；
- 同类 V4 样本尚未形成 20 笔以上、PF 低于 0.75 且净收益为负的明确反证。

通过后使用阶段基础风险的 `0.5x`。该倍率只在候选风险中应用一次，之后仅叠加 V4 独立信用、权益保护和目标保护。

### 已验证准入

同市场状态、方向和信号类型的 V4 样本达到 40 笔，PF 不低于 1.10，且考虑不确定性后的净期望下界不低于 0.02%，才允许 `1.0x` 标准倍率。

## 证据隔离

- 当前实盘发布为 `extreme_v4_roll@v4.0`。
- V3.2 发布转为历史归档；旧 V3 负证据不会触发 V4 的版本热身阻断。
- V4 拥有独立币种方向信用分、实时反应和策略证据。
- V4 继续记录决策、探索和同机会对照影子，PF 必须连同样本数、成本和净收益解释。
- 更换 V4 模型时必须更换策略版本号，不混用历史证据。

## 性能与 API

- 不增加 Binance REST 扫描或下单调用。
- V4 复用现有候选、公共 WebSocket、深度竞价结果和衍生品检查。
- 影子证据读取本地 SQLite，并保持 60 秒缓存。
- 每轮影子上限仍为决策 3、探索 6、同机会对照 3，控制数据库体积。

## 不变的硬边界

- 5U 权益硬停止不可绕过。
- 真实持仓必须有交易所端止损和止盈，缺失时自动补单。
- 最小下单量、盘口流动性、手续费和滑点成本检查仍生效。
- Binance REST 权重、订单频控、时间同步和裸仓审计仍生效。
- V4 版本自身出现严重负期望、连续止损或异常回撤时，性能保护仍会阻止新开仓。

## Dashboard

- 机会中心直接显示 V4 排名、准入状态、保守净期望和同类证据。
- V3 A+/A/B 明确标记为历史诊断。
- 实盘学习默认展示 V4 独立信用，V3 信用收进历史复盘。
- 策略实验室把 V4 显示为当前实盘发布，不再显示成等待自动接管的候选。
