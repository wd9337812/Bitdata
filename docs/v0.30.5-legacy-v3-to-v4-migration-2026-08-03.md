# v0.30.5 旧 V3 持仓迁移审计

日期：2026-08-03

## 问题

V4 已替换旧 V3 的新开仓规则，但部署时仍存在一个受保护的 V3 ETH 持仓。兼容逻辑会继续管理它最多 20 天，而 S0 只允许一个持仓，因此新 V4 即使出现合格信号也可能长期无法执行。

## 修复

- 旧仓不会因为部署、版本变化或普通扫描而被强制退出。
- 每次仅用假设平仓后的真实权益重新计算 V4 可执行性。
- 只有 V4 日线信号仍在两小时新鲜窗口内、BNB 合约最小量满足、5U 硬停止余量满足且新开仓开关开启时，才退出旧 V3。
- 旧仓退出后本轮结束；下一轮会重新读取 Binance 账户，再按 V4 下单，避免用平仓前的余额快照连续操作。
- V4 信号过期、不可执行或无信号时，旧仓继续由原交易所止损、止盈和 V3 日线管理保护。

## 不变的安全边界

- 5U 硬停止不变。
- 不移除 Binance 条件止损和止盈审计。
- 不放宽最小下单量、API 限频或时间同步。
- 当前 V4 仍使用固定 BNB、10% 止损、最长五日和新鲜日线窗口。
