# v0.22.0 MoE 线上证据迭代

日期：2026-07-24

## 目标

解决 Dashboard 长期显示固定 `491 笔 / PF 1.06`、无法判断线上 MoE 是否产生新样本的问题，同时修正线上信号类型与离线专家类型不一致。

## 变更

- MoE 模型包升级为 `s0_binance_moe_v1_1`。
- `breakout` 明确复用 `momentum` 专家；门控仍按专家和市场状态分别验证。
- `broad_down`、`rotation` 等未通过样本外验证的单元保持关闭。
- 线上统计只读取当前 `V4.11` 策略版本和当前 MoE 模型版本。
- 分开统计“全部已评估”“存在有效门控”“通过门控”三类影子。
- 只有“通过门控且已结束”的影子才计算线上 MoE 胜率、PF 和净收益。
- Dashboard 同时展示线上门控影子、离线未触碰测试和候选重训练进度。
- 新增受控快照脚本。实盘样本权重为 3，影子样本权重为 1；权重只写入训练元数据，不影响线上开仓。
- 候选达到最少 200 笔闭合门控样本、覆盖至少 2 种市场状态后，仅表示可以开始本地候选训练，不能自动替换线上模型。

## 训练复现

数据：Binance 1 分钟数据，2,143,799 行，119 个币。

- 验证集：506 笔，PF 1.2978，净收益 94.045 个百分比点。
- 未触碰测试集：491 笔，PF 1.0627，净收益 22.500 个百分比点。
- 成本假设：往返 0.12%。
- 0.16% 成本时 PF 仅 1.0078，说明优势较薄，维持影子模式。

## 安全与性能

- 不修改 V4.11 实盘准入、仓位、杠杆、止盈或止损。
- 不新增 Binance REST 请求。
- 线上证据从本地 SQLite 读取并缓存 30 秒，单次最多读取当前版本最近 50,000 条影子。
- 5U 硬停止、交易所止盈止损、最小下单量、限频和裸仓保护保持不变。
