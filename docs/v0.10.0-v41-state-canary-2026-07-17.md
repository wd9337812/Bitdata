# v0.10.0 / V4.1 状态自适应与新策略许可证

## 目标

V4.0 的影子结果证明，统一阈值与统一 PF 不能准确代表所有山寨币机会。本次迭代不通过提高杠杆制造收益，而是先修正选币证据、成本口径和新策略在 `risk_off` 中无法获得实盘样本的问题。

## 证据结论

- V4.0 决策影子整体扣费后表现不足，但不同市场状态差异明显，不能继续使用单一全局结论。
- `quiet + SHORT` 的突破、回踩和预突破组合在历史样本中相对较好；`mixed + LONG + pullback` 只具备小样本试验价值。
- `RETEST` 的扣费后表现优于直接 `TRIGGERED` 追价；中周期方向一致的样本明显更稳。
- 模型估算扣费后期望达到 `0.10%` 以上的样本表现较好，因此 V4.1 把动态成本和保守期望设为实盘硬门。
- 分数与结果并非单调关系，因此 V4.1 不再把“分数越高”直接等同于“仓位越大”。

## V4.1 选币与证据

1. 准入主键为 `市场状态 × 方向 × 信号类型 × 入场阶段`。
2. 同一个 `opportunity_id` 只记一次独立决策结果。
3. 只有 `decision` 影子参与准入、PF 和恢复证据；`exploration` 与 `paired_control` 只做研究。
4. 经验权重采用带先验的收缩估计，避免小样本立刻覆盖模型。
5. 动态成本取候选实测成本与“往返手续费 + 滑点 + 点差 + 0.02% 安全缓冲”的较大值。
6. 最低模型净期望默认 `0.10%`，保守下界必须大于零，毛利/成本比默认至少 `2.0`。
7. 中周期方向默认必须一致；`RETEST` 优先，`ARMED` 次之，`TRIGGERED` 追价额外降分。

## 状态路线

- `quiet + SHORT + breakout/pullback/prebreakout`：允许进入证据晋级路线。
- `mixed + LONG + pullback` 与顺势 `broad_up + LONG`：只允许新策略许可证小仓验证。
- `broad_down / panic / rotation`：当前证据不足，保持影子观察。
- 其他组合：不全局放宽，继续积累独立决策样本。

## 证据晋级

- 新策略试运行：同轮排名前 15%、模型质量至少 58、成本和状态硬门全部通过，默认 `0.4x`。
- 受限准入：至少 200 个同类独立决策机会、扣费后 PF 至少 1.10、净收益和保守下界为正，默认 `0.7x`。
- 标准准入：至少 500 个同类独立决策机会、PF 至少 1.15，并跨至少 2 个时间块和 3 个币种，默认 `1.0x`。

## 新策略试运行许可证

- 只授权 `extreme_v4_roll@v4.1`，策略版本不匹配时无效。
- 仅在全局 `risk_off` 时签发，默认有效 24 小时。
- 一级默认最多 3 个受保护机会、`0.4x`；一张单未结束时不能再开下一张。
- 从签发后开始统计：3 笔实盘净收益为正且 PF 至少 1.05，升级 `0.7x`；8 笔净收益为正且 PF 至少 1.15，升级 `1.0x`。
- 默认累计 2 笔亏损即撤销；保护单确认失败立即撤销。
- 许可证只穿透旧策略的负证据背景，不穿透 5U 硬停止、冷却期、交易所最小量、API/时间安全、流动性、成本和 V4.1 候选门槛。

## 入场阶段保护

- `RETEST`：止损 `0.70 ATR`，止盈 `1.25 ATR`，最长 `10` 根 5m K 线。
- `ARMED`：止损 `0.62 ATR`，止盈 `1.05 ATR`，最长 `6` 根。
- `TRIGGERED`：止损 `0.70 ATR`，止盈 `1.20 ATR`，最长 `8` 根，并在选币模型中降低追价得分。

## 性能与 API

- 复用现有漏斗、K 线、盘口和 WebSocket 数据，不新增 Binance 高频轮询。
- V4.1 证据查询按版本、证据类型、状态和时间建立索引，并保留 60 秒缓存。
- 新许可证状态保存在现有原子状态文件中，不新增数据库高频写入。
- 每轮影子上限保持决策 3、探索 6、对照 3，避免扩大 VPS 与数据库压力。

## 不变的安全边界

- 5U 权益硬停止不变。
- 实盘持仓必须同时存在交易所端止损和止盈。
- 最小下单量、时间同步、REST 频控、公共/私有 WebSocket 与裸仓审计不变。
- 本次不提高 S0 杠杆，不承诺收益或阶段目标一定实现。
