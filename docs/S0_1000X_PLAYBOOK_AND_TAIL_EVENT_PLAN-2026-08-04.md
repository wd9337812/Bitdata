# S0 千倍路径：尾部事件方案（2026-08-04）

## 一、先回答“有没有 30% 风险 / 65% 胜率 / 全仓短打”

没有，而且这组参数在这套系统里已经被反复证伪：

1. **账户自己 7 月的尸检**：827 笔实盘短打，净亏损 -50.62U，手续费 69.91U，胜率 36.5%，PF 0.90；权益从 33.67U 被打到 5.17U。高频短打不是“没放大”，而是放大后直接亏完。
2. **仓库正期望研究（2026-08-01）明确结论**：S0 的主要矛盾不是杠杆不够，而是候选没有稳定的扣费后方向优势；放大负期望只会更快触发 5U 硬停止。
3. **胜率目标错位**：趋势/尾部策略的胜率天然在 35%-55%，靠少数大赢家赚钱；65% 胜率 + 30% 风险意味着必须高频小止盈，而这正是手续费杀手（7 月 69.9U 手续费）。
4. **30% 风险平铺**在 2026 年按年重启触发 5U 硬停止；只有在权益 ≥30U 且以阶梯方式启用时才有操作空间。

## 二、别人怎么短期做千倍

公开案例（凉兮式、meme 币季、新币上市）的共同点不是 65% 胜率，而是：

- **事件驱动的巨大不对称**：新币上市、暴涨崩盘、资金费极端拥挤，单次机会 10-50R。
- **少数大赢家**：低胜率（30-50%），但赢家一笔覆盖几十笔亏损（PF > 3）。
- **高杠杆押注高确信事件**：10-100x 只在事件确认后进场，止损极小。
- **小本金快速复利**：15U → 100U 靠 2-3 笔 3R 连胜；100U → 1000U 靠 1 笔 10R 级别的行情。

结论：要千倍，靠的是“抓尾部事件 + 让利润奔跑 + 高杠杆”，不是“65% 胜率小止盈”。

## 三、三阶段方案

### Phase 0：立即做（有证据、可部署）

- 风险阶梯：<30U 用 20%，≥30U 升 25%（历史全序列 1380.85U vs 现行 1256.75U，按年重启无 5U 硬停止）。
- 杠杆：2x → 3x（25% 在 12.5% 止损距离下需要约 2.0 倍名义仓位，3x+90% 保证金可执行）。
- 止盈/止损/持仓不变：3.5R、2.5 ATR、5 天。
- 目的：在现有正期望上放大 10%+，不引入负期望。

### Phase 1：尾部事件识别器（2-4 周研究，仓库已指明方向）

- 标签：扣费后最大有利波动（MFE）是否 ≥ 2×（止损+成本），而不是预测下一根涨跌。
- 特征：横截面加速度、成交量冲击、taker 失衡、资金费变化、持仓量变化、盘口可执行成本；只用当时可见数据。
- 切分：2020-2023 开发 / 2024 验证 / 2025 测试 / 2026 盲测；模型只排序和拒绝，仓位仍由确定性风控引擎执行。
- 放行门槛：模型前 1% 候选的扣费后 PF > 基线、跨年成立、去掉头部 1 币仍为正、无 5U 硬停止。

### Phase 2：事件驱动集中押注（模型或规则通过后）

- 候选：新币上市 72 小时动量延续（仓库只测过“上市回落做空”，做多一侧是盲区）、资金费极端拥挤反转、暴涨后 1 小时内的动量延续/衰竭反转。
- 资金：单笔风险 30%（仅权益 ≥30U 时）、杠杆 3-5x、保证金 90%、5U 硬停止。
- 止盈：10-50R 移动止盈（让尾部奔跑），止损 2.5 ATR；持仓 1-5 天。
- 顺序：影子 2 周（≥50 笔、PF>1.2、无硬停止）→ 30% 资金小仓 → 全量。

## 四、诚实结论

千倍是小概率事件，任何声称稳定做到的都是幸存者偏差。这个方案的意义是把概率往右偏：不做 65% 胜率短打，而是用验证过的 30 日动量打底、用尾部事件识别器去找 10-50R 的机会、用 25-30% 风险 + 3x 杠杆放大。若 Phase 1 两年内找不到跨年正期望的尾部模型，就该承认当前账户规模下 10000U 不可行，而不是继续加杠杆赌命。
