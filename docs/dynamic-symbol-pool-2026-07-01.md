# 动态机会池与模拟准入 2026-07-01

## 背景

上一轮扩展扫描池后，系统捕捉到了更多机会，但 `ZBTUSDT` 这类高波动币在进入实盘池时缺少币种准入判断。问题不在于单次止损，而在于“策略信号通过”不等于“这个币现在适合实盘交易”。

## 新逻辑

每轮扫描仍然按当前模式运行，小资金阶段默认 5m 锦标赛策略。不同的是，每个候选币必须先通过币种质量评分：

- `trade`: 允许标准实盘。
- `small_trade`: 允许小仓试探，自动乘以 `small_trade_risk_multiplier`。
- `observe`: 只观察和记录，不实盘。
- `disabled`: 暂不交易。

开仓条件变为：

1. 策略信号通过。
2. 历史策略回测通过。
3. 币种质量评分达到准入线。
4. 模拟表现达标。
5. 扣除手续费和滑点后仍有足够利润空间。
6. 盘口点差和 5 档深度必须达标，否则即使评分够也只能观察。

## 评分组成

`symbol_quality.score` 满分 100，主要由以下部分组成：

| 项目 | 目的 |
| --- | --- |
| 24h 成交额 | 过滤低流动性币 |
| 5m 成交放大 | 捕捉正在活跃的机会 |
| ATR 波动率 | 太低没利润，太高容易被扫 |
| 盘口点差与深度 | 控制真实滑点 |
| 3/5/10 天回测 | 避免单一窗口过拟合 |
| 趋势一致性 | 当前结构要支持信号方向 |
| 假突破惩罚 | 样本太少、胜率太低、波动过高会扣分 |

## 默认阈值

- 标准实盘：`symbol_trade_score >= 75`
- 小仓试探：`symbol_small_trade_score >= 65`
- 观察池：`symbol_observe_score >= 50`
- 模拟最少信号：`min_simulated_trades = 5`
- 模拟胜率：`min_simulated_win_rate = 45%`
- 模拟 PF：`min_simulated_profit_factor = 1.25`
- 模拟净收益：`min_simulated_net_pct = 1.5%`
- 最大盘口点差：`max_spread_pct = 0.08%`
- 最小 5 档盘口深度：`min_depth_notional_usdt = 20000`

## 对 ZBTUSDT 的修正

旧逻辑里，`ZBTUSDT` 因为策略分数高、5 天回测可接受，直接进入标准实盘。

新逻辑会额外检查：

- 最近 3/5/10 天是否同时稳定。
- 盘口深度和点差是否足够。
- 模拟信号数是否至少 5 笔。
- 是否存在高波动假突破惩罚。

如果不达标，即使出现标准突破信号，也只能进入观察池或小仓池，不会直接标准仓位实盘。

本次上线后，盘口深度是硬门槛，不再只是扣分项。类似 `ZBTUSDT` 这种高波动币，如果 5 档深度不足 `20000U`，会被挡在实盘池外。

## 上线方式

本次实现不依赖每日批处理。每轮扫描都会重新计算质量分，因此机会池可以随行情快速变化。未来如果扫描成本过高，再增加 5 分钟缓存层。
