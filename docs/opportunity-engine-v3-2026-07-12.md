# Bitdata 机会引擎 V3

日期：2026-07-12  
版本：`v0.4.0`  
策略族：`extreme_v3_roll`

## 目标

S0-S2 不再依赖“24h 涨跌幅热点 + 每轮短窗回测 + 旧策略信用”的叠加过滤，而是先判断全市场环境，再寻找相对强、结构刚触发、量价确认且扣费后仍有空间的山寨币趋势机会。

本版本提高的是机会筛选、执行一致性和样本真实性，不承诺固定收益，也不代表小资金能在指定期限达到目标权益。5U 硬停止线、每日亏损限制、权益保护、最小下单量、持仓保护单和换仓成本校验均保留。

## 实时架构

1. **一次全市场横截面**：使用单次 24h ticker 计算上涨广度、中位涨跌、离散度、成交额分位和每个币的相对强弱。
2. **低成本召回与粗排**：优先保留相对强弱、成交额、残差涨跌和 WebSocket 异动靠前的币。
3. **K 线结构精排**：使用 EMA 10/20/50、Donchian 12/24/48、1/3/12/48 根收益、部分 K 线成交额归一化和主动成交方向。
4. **高成本竞价**：只给入围币读取盘口深度与 OI；资金费、基差、OI 和价格方向用于确认或降权。
5. **统一机会分**：满分 100，依次包含相对强弱 25、趋势 20、量价 15、突破 15、市场适配 10、衍生品 8、流动性 7，并扣除插针、末端加速、事件过期、成本拖累和逆势惩罚。
6. **统一执行收口**：候选仍经过 V3 独立信用、实时连续亏损反应、最小下单量、有效订单收益和实际交易风控。

## 机会分层

| 档位 | 默认条件 | 实盘行为 |
| --- | --- | --- |
| A+ | 分数 >= 82，收益/真实成本 >= 3.0 | 可使用阶段风险上限；所有硬风控继续生效 |
| A | 分数 >= 70，收益/真实成本 >= 2.0 | 默认 0.65 倍风险，再叠加行情、衍生品和信用倍率 |
| B | 分数 >= 58，收益/真实成本 >= 1.35 | 默认只建立影子交易，不下实单 |
| WATCH | 未满足结构、强弱、流动性或成本条件 | 继续观察 |

做空默认要求更高的横截面强度分位，并在全市场上涨时额外扣分。单根急跌并伴随明显反向影线时禁止追空。

## 市场自适应

市场分为广泛上涨、广泛下跌、恐慌下跌、高离散轮动、低波动震荡和混合震荡。分类使用当轮真实横截面数据，不使用隔日缓存。不同状态只改变机会分和风险倍率，不绕过止损、日损或硬停止线。

## 信用与恢复

- V3 使用独立 `extreme_v3_roll` 信用账本；旧 `extreme_v2_roll` 只展示，不参与 V3 仓位。
- 新币从 50 分开始。正常情况下 V3 信用倍率限制在 0.80-1.20 倍，避免旧样本把新引擎直接压成无效小仓。
- 近期亏损和冷却时最低倍率可降至 0.35；实时连续亏损模块仍可暂停同币种同方向。
- 全局负期望保护改为 0.20、0.40、0.70、1.00 四档恢复。旧窗口冷却期间，只有 V3 A+ 可按 0.35 倍进行受限验证。
- A+ 受限验证不能绕过 5U 硬停止、每日亏损、权益保护、最小下单量或持仓保护。

## 影子交易

- 只有实际触发方向且达到 V3 B 级以上的候选才建立 V3 影子单。
- 活跃影子单使用本地 WebSocket 全市场 ticker 更新，不依赖该币下一轮是否再次进入候选。
- 有 1 分钟 K 线订阅时使用当分钟最高/最低判断止盈止损；同一观察间隔同时穿越两条线时保守按止损先发生。
- 每笔记录策略族、市场状态、机会分、信号类型、成本和净结果，供后续按行情状态做离线回放。

## 性能和 API 开销

- V3 实时扫描不再对每个币、每个方向重复运行 2/3/5 天窗口回测；回测转为离线验证。
- 全市场行情横截面优先读取本地 `!ticker@arr` WebSocket；流数据不足时才使用 30 秒缓存或一次 REST ticker。Binance 当前文档标明无 `symbol` 的 24h ticker 权重为 40，因此不能按币逐个重复请求（[官方文档](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data#ticker24hr-price-change-statistics)）。
- 影子交易读取本地 WebSocket 快照，不增加 Binance REST 请求。
- OI 和盘口仍受竞价预算、扫描时间预算和现有 Binance 请求权重控制。
- SQLite 延续 WAL、`busy_timeout`、日志节流和分批留存清理；影子表仅增加三个轻量字段。

## Dashboard

- 多币种扫描新增 V3 市场状态、A+/A/B/WATCH 数量和真实成本线。
- 候选表新增机会档位、V3 评分拆分和市场状态。
- V3 实时行不显示伪造的“0 次回测/PF 0”，而标记为离线验证。
- 实盘学习首页改为 V3 独立信用；V2 与剥头皮账本保留为历史或后续阶段数据。

## 上线检查

1. 升级前查询真实持仓、普通订单和条件止盈止损。
2. 有持仓时确认交易所侧保护单完整后才重启容器。
3. 升级后确认 S0-S2 路由为 `extreme_v3_roll`、公共和私有 WebSocket 正常。
4. 确认 `opportunity_v3_enabled=true`、`hard_stop_equity=5`、实盘开关和 API IP 白名单未变化。
5. 启动后检查第一轮 V3 漏斗、REST 预算、影子更新和保护审计。
