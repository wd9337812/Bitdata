# 极限剥头皮信用试验层与机会放宽记录

日期：2026-07-09

## 背景

盘口剥头皮引擎上线后，旧策略历史亏损会通过“币种 + 方向”的实盘信用分继续影响新信号，导致新引擎即使出现盘口冲击、放量剥头皮或失衡试探，也可能因为旧信用低分、冷却或熔断而无法收集足够新样本。

本次迭代不删除历史记录，而是为盘口剥头皮增加试验层：旧信用继续展示和留档，但只作为仓位软折扣，不再硬熔断新引擎。

## 变更

- 新增剥头皮信用试验层：
  - `yolo_scalp_credit_experiment_enabled=true`
  - 盘口剥头皮 entry type：`orderbook_impact`、`volume_scalp`、`imbalance_probe`
  - 新引擎信用从 50 分起步，旧信用保存在 `legacy_live_credit`
  - 旧信用低分或冷却时，默认只打 `0.70x` 软折扣
- 小幅放宽盘口剥头皮机会：
  - 最小盘口失衡：`0.08 -> 0.05`
  - 强盘口失衡：`0.18 -> 0.14`
  - 失衡试探最低 depth5 深度：`300U`
  - 收益/成本比：`1.15 -> 1.05`
  - 扣费后净空间：`0.04% -> 0.025%`
- 增加强盘口方向试探：
  - 实时方向不一致但盘口失衡很强时，只允许按 `imbalance_probe` 小仓试探。
  - 仍保留点差、深度、实时异动、扣费后空间和最长持仓保护。

## 安全边界

- 不改变实盘下单 API 和保护单逻辑。
- 不改变已有止盈止损、最长持仓、盘口失效退出。
- 不删除旧历史，旧信用仍用于展示和软折扣。
- 普通策略仍使用原实盘信用分，不进入试验层。

## 观察指标

- 新剥头皮信号通过数量是否上升。
- `legacy_live_credit` 很低的币种是否仍能小仓试验。
- 新策略真实成交后的净收益、手续费占比、快速止损次数。
- 如果连续亏损扩大，应优先收紧试探深度、收益/成本比和方向试探，而不是直接关闭整套引擎。
