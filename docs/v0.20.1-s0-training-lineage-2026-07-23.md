# v0.20.1 S0 训练数据血缘

## 目的

第二轮公开行情训练表明，单靠公开 K 线产生的大样本不能替代真实决策现场。此次迭代不修改 V4.10
策略阈值，只补齐下一轮训练需要的高权重数据链：

`候选机会 -> V4 决策 -> Binance 下单 -> 成交 -> 保护单 -> 平仓 -> 扣费后标签`

## 新数据契约

每个进入影子或实盘决策的机会都带有 `opportunity_id`。实盘下单后同时保存 Binance
`orderId`、止损 `algoId` 和止盈 `algoId`。平仓同步优先用开仓 `orderId` 精确回连，不再只按币种
和时间猜测。

新表 `opportunity_lineage` 保存：

- 当前策略家族、精确版本、方向、信号类型、市场状态和准入通道。
- 决策价、止损、止盈、计划数量、杠杆和风险。
- 最近 12 根 1 分钟 K 线、盘口点差、深度、微价格和主动成交方向。
- 实际开平仓均价、开平仓手续费、资金费、方向化滑点、净盈亏、持仓时间和退出原因。

旧实盘若无法通过订单号回连，只标记为 `approximate_time` 或 `unmatched`，后续训练不得与
`exact_order_id` 样本等权。

## 性能与 API

- WebSocket 内存中每币种只保留最近 12 根 1 分钟 K 线。
- 150 个币约 1800 根短记录，不增加 Binance REST 请求。
- 只在影子候选或最终决策时写数据库，不按 tick 写盘。
- 单次同步仍复用现有 `/fapi/v1/userTrades`，没有新增逐币轮询接口。

## Dashboard

“系统”页面新增“模型训练数据质量”，显示：

- 带分钟快照的机会数。
- 实盘订单号精确回连数和覆盖率。
- 旧记录未匹配数。
- 带真实滑点的样本数。
- 影子样本数量及是否达到首轮高权重训练门槛。

## 训练门槛

首轮高权重再训练的最低自动提示条件为：

- 至少 30 笔订单号精确回连的已结束实盘；
- 至少 100 条带分钟快照的机会。

达到门槛只表示“可以开始训练”，不代表候选模型有资格接管实盘。模型仍需时间隔离、扣除
手续费与滑点的样本外回放，并与线上 V4.10 正面对照。

## 导出

```powershell
python scripts/export_training_dataset.py --limit 5000
```

默认输出 `data/training/s0_lineage.jsonl`。接口
`GET /api/training-data/quality` 用于质量审计，
`GET /api/training-data/dataset?limit=500` 用于受认证的结构化导出。
