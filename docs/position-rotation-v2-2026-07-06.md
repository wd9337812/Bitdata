# 持仓轮换 V2 留档

日期：2026-07-06

## 背景

极限模式下允许一次只持有少量仓位时，会遇到一个问题：当前已经有仓位，但扫描器又发现了更强的新突破信号。如果系统只因为“已有持仓”而拒绝新机会，就会错过更高质量的火药桶、小仓抢跑或标准突破。

本次迭代目标是让系统在已有持仓时自动比较“旧仓位”和“新信号”，只有当新信号明显更好，并且预期空间足以覆盖换仓成本时，才执行自动平仓并切换到新仓位。

## 核心规则

1. 轮换只在 `position_rotation_enabled=true` 且当前模式开启对应轮换开关时生效。
2. 极限模式新增 `extreme_sprint_rotation_enabled=true`，默认允许轮换。
3. 新机会必须先通过原有入场逻辑，包括抢跑、火药桶、信用分、币种质量、成本比、风险限制等。
4. 如果达到最大持仓数，系统会对比当前持仓中最弱的一笔和新候选。
5. 新候选必须满足最低分、分差、原始成本比、换仓净成本比。
6. 当前仓位如果已经是明显盈利单，会提高替换门槛，避免把好单频繁换掉。
7. 当前仓位如果处于小亏或探索型入场，允许更敏捷地替换。

## 手续费与滑点

换仓不是只看新单的开仓成本，还要考虑旧仓平仓成本。本次新增：

- `rotation_extra_close_cost_pct`：默认 0.08%，用于估算平掉旧仓的额外手续费和滑点。
- `rotation_min_net_cost_ratio`：默认 2.5，表示新信号的预期空间至少要覆盖换仓总成本 2.5 倍。

计算逻辑：

```text
换仓总成本 = 新单估算成本 + 旧仓平仓额外成本
换仓净成本比 = 新信号预期空间 / 换仓总成本
```

如果换仓净成本比不足，系统会返回 `rotation_cost_ratio_too_low`，不会执行换仓。

## 动态分差

不同旧仓状态使用不同替换门槛：

- 探索型或抢跑型旧仓：默认最小分差 8 分，更容易被高质量信号替换。
- 小亏旧仓：默认最小分差 8 分，允许快速纠错。
- 盈利旧仓：默认最小分差 25 分，避免过早换掉正在赚钱的仓位。
- 极限模式盈利保护阈值：`rotation_keep_winner_profit_pct_extreme=1.2`，比普通模式更敏捷。

## 执行安全

真正换仓时沿用现有执行链：

1. 取消旧币种普通挂单和止盈止损条件单。
2. 市价平掉旧仓。
3. 按新候选计算仓位。
4. 市价开新仓。
5. 重新挂止盈止损保护单。

系统不会因为扫描到更高分候选就无条件换仓，必须先通过成本、分差和风险保护。

## 验证

已新增测试：

- 更强的极限模式探索信号，在覆盖换仓成本后允许替换。
- 新信号分数很高但预期空间不足以覆盖换仓成本时禁止替换。
