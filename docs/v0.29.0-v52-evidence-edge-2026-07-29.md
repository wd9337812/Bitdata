# v0.29.0 / V5.2 独立行情段与成本优势

日期：2026-07-29

## 背景结论

本次迭代基于 VPS 全量实盘、当前版本影子与实盘/影子配对复盘：

- 历史 817 笔实盘毛收益约 `+24.18U`，手续费约 `69.69U`，资金费约 `-3.28U`，最终净收益约 `-48.79U`。成本覆盖是长期首要问题。
- 同币同向在一次亏损后 5 分钟内再次入场的 88 笔交易，胜率约 `20.45%`，净收益约 `-33.09U`。同一失败行情重复入场必须禁止，除非结构已重置。
- 当前版本影子按原始机会统计会把同一波行情重复计算。按“币种 + 方向 + 形态 + 30 分钟间隔”压成独立行情段后，证据更接近可复现实盘机会。
- 当前版本影子中，突破/预突破且横截面强度较高的样本明显优于纯动量样本。该结论只用于 V5.2，不反向污染旧版本。

## V5.2 准入流程

1. 保留现有召回、粗排、精排、盘口检查和交易所最小量检查。
2. 当前版本影子证据按 30 分钟独立行情段去重；数据库保留全部原始记录。
3. 质量评分权重调整为：
   - 横截面强度 25%
   - 市场与中周期趋势 25%
   - 形态和入场质量 15%（形态类型另作有界修正）
   - 放量与方向资金流 17%
   - 防追高与流动性 18%
   - 聪明钱仅作有上限的软修正，不可独立触发实盘
4. 纯动量追涨默认只做影子；实盘只接受突破、预突破或回踩结构。
5. 横截面强度默认至少 `0.78`。
6. 预期毛利默认至少覆盖动态往返成本 `3.5` 倍。
7. 同币同向亏损后，在同一行情事件内禁止重进；出现回踩、路径、量能和延伸共同确认的结构重置后才恢复。

## 仓位与硬停止

- 机会质量先映射为 `12% / 18% / 24% / 30%` 请求风险。
- `30%` 是配置上限，不是每笔无条件风险。
- 下单时计算：

  `可用风险上限 = (权益 - 5U硬停止 - 0.15U预留) / 权益`

- 实际风险取“质量请求值、30% 配置上限、压力成本上限、硬停止余量上限”的最小值。
- 例如权益 `6.99U` 时，硬停止余量上限约 `26.3%`；权益恢复到足够水平后，顶级机会才可能使用完整 30%。

## 证据与退出归因

- Dashboard 同时显示原始机会数和独立行情段数。
- 当前版本同类证据达到最少独立行情段后，负 PF 只降低该同类机会仓位，不做全局永久停牌。
- 无法归入交易所止盈或止损的退出，进一步区分为运行时盈利退出、运行时亏损退出和运行时持平退出，方便后续判断快速退出是否真正有效。

## 安全边界

以下规则没有放宽：

- `5U` 权益硬停止
- 每个真实持仓必须同时具有交易所端止损和止盈
- 裸仓自动补保护
- 最小下单量、流动性硬门、API 限频和时间同步
- MoE 仅作研究影子，不接管实盘
- 不清空任何历史数据，不混用不同策略版本证据
