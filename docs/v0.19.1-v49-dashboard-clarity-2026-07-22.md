# v0.19.1 V4.9 Dashboard 展示口径整理

日期：2026-07-22

## 问题

V4.9 后端只使用一份全局动态校准快照，但候选表把这份快照重复显示在每个币种行内，并把 `relation=global` 误显示为“中性”。这会让人误以为系统仍在针对单个币种动态调参。

首页的“下单余额快照”还读取了状态接口中不存在的字段，容易显示错误的刷新状态。设置页同时混用 V4.7、V4.8 和 V4.9 文案，难以判断哪些参数仍参与当前实盘。

## 调整

- 候选表明确区分“币种自己的实时指标”和“全局共享校准”。
- V4.9 全局校准显示 24 小时影子/实盘样本、PF 和全局状态，不再显示单币种的顺势/中性/逆势关系。
- 首页新增四步开仓决策说明，解释币种筛选、全局校准、交易硬门和执行保护。
- “下单余额快照”改为真实的账户投影状态，并说明下单前仍会强制复核余额。
- 当前版本仍使用的历史配置键改用业务含义命名；退出实盘的参数明确标为归档或兼容。
- 清理活动页面中的 V4.7/V4.8 旧文案，显示实际当前版本。

## 边界

本版本只调整 Dashboard 展示和说明，不改变 V4.9 排名、准入、仓位、杠杆、止盈止损、许可证或全局校准算法。
