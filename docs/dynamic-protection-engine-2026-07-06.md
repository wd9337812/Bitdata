# 动态保护计划迭代留档

日期：2026-07-06

## 背景

极限冲刺和锦标赛阶段需要更快地试错、止盈和止损。此前系统已经能按不同入场类型生成不同的 ATR 止盈止损参数，但保护逻辑散落在扫描信号和下单执行之间，不利于后续继续做“快速失效、保本、移动止盈、持仓超时退出”等功能。

本次迭代新增统一的动态保护计划模块，让每一笔候选交易在进入下单前都生成一份可审计的保护计划。

## 已实现

1. 新增 `app/protection.py`
   - 根据方向、多空、入场类型和 `protection_profile` 生成保护计划。
   - 支持标准、抢跑、动量、火药桶试探、弱质量试探、观察池试单等入场类型。
   - 生成初始止损、初始止盈、快速失效线、保本触发线、移动止盈触发线。

2. 接入实盘下单入口
   - `build_stage1_decision` 会在风控和仓位计算前应用动态保护计划。
   - `execute_stage1_market_order` 使用保护计划里的初始止损/止盈下保护单。
   - 如果关闭 `dynamic_protection_enabled`，执行层会回退使用原始信号止盈止损。

3. 新增可配置项
   - `dynamic_protection_enabled`
   - `protection_fast_invalid_seconds`
   - `protection_fast_invalid_atr`
   - `protection_break_even_trigger_atr`
   - `protection_break_even_buffer_pct`
   - `protection_trailing_trigger_atr`
   - `protection_trailing_distance_atr`
   - `protection_min_profit_after_cost_pct`

4. Dashboard 展示
   - 当前策略解释里展示保护档案、止损/止盈 ATR、初始止损、初始止盈。
   - 配置中心进阶参数里开放动态保护相关配置。

## 当前边界

本次已经把“初始保护单”接入实盘下单。快速失效、保本、移动止盈目前先作为结构化计划输出和留档字段，后续可以接入持仓监控循环，对已有保护单进行撤单重挂或市价退出。

这样分阶段更稳：先保证新开仓的保护单价格来源统一、可解释、可测试，再做持仓期间的动态改单。

## 测试覆盖

新增测试覆盖：

- 多单保护计划按 ATR 生成更快止盈止损。
- 空单保护计划正确反转止损和止盈方向。
- 关闭动态保护后信号价格不被覆盖。
- 执行层不会使用已关闭的动态保护计划价格。

## 风控说明

动态保护不是“放大风险”，而是让不同类型的交易有不同的认错速度：

- 弱质量试探：止损和止盈更近，用更小仓位快速学习。
- 抢跑：止损更紧，避免假突破拖太久。
- 动量/标准：给趋势更多空间，但仍记录保本和移动止盈触发线。

后续如果接入持仓监控动态改单，需要额外注意 Binance 频控、撤单重挂失败兜底、以及当前持仓方向是否已经变化。
