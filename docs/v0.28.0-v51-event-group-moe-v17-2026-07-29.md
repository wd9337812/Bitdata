# v0.28.0 / V5.1 事件候选与 MoE v1.7

## 本轮目标

本轮把 V5.0-S30 的单仓全进全出短打推进为 V5.1 候选。目标不是无条件增加交易次数，而是在恐慌行情中给满足恢复结构的候选一个可审计入口，同时避免把同一波行情的重复影子当成多个独立机会。

## V5.1 策略变更

- 保留单仓、全进全出、快速保护、5U 硬停止、最小下单量、流动性硬门和交易所止盈止损。
- 恐慌行情默认仍为 `panic_shadow_only`。
- 只有回踩/预突破结构、RETEST/ARMED、趋势一致、量能、方向资金流、中周期路径和防追高全部通过，才进入 `panic_recovery_candidate`。
- 回踩、预突破、突破使用独立排名、成本和确认门槛；突破要求更强确认。
- 新增 `event_group_id`，按币种、方向和 60 分钟行情波段归组，用于影子统计和训练去重，不增加 Binance API 请求。

## MoE v1.7

训练范围只使用 V5 实盘与影子主证据，公开 Binance 数据只作为低权重训练支持。v1.7 新增：

1. 按事件组做时间切分，训练、验证、测试不得共享同一行情波段。
2. 对同一事件组的重复影子限权，避免一波行情重复计票。
3. 同时计算 1.0x、1.5x、2.0x 成本压力。
4. 固定 `affects_live_admission=false`，模型不自动接管实盘。

本地训练结果：

- 3965 条去重 V5 样本，3960 个独立事件组。
- 验证段 14 笔，1.5x 成本后 PF 2.2216、净收益 4.19622 个百分点，但只有 1 种市场状态。
- 未触碰测试段 16 笔，1.5x 成本后 PF 0.1776、净收益 -11.15082 个百分点。
- 结论：`research_shadow_only`，不能进入实盘准入。

## 回滚

可将 `opportunity_v4_strategy_version` 恢复为此前发布的 V5 版本。不同版本证据必须隔离，不删除历史记录。
